# Privacy and children's data

Greenfield Academy is the data controller. Collect only records needed for education, safeguarding, attendance, communication, and lawful fee administration. Publish a clear parent notice describing purpose, retention, access, correction, and complaint routes under Kenya's Data Protection Act, 2019.

- Restrict learner records by role and class allocation.
- Never expose class lists through learner accounts.
- Encrypt traffic and server volumes; keep secrets outside source control.
- Record access and changes to marks, identity, attendance, fees, and reports.
- Review devices and staff permissions each term.
- Export a learner's record for an authorised data-subject request.
- Delete or anonymise records only under the school's approved retention schedule.
- Use signed provider agreements for hosting, SMS, and payments.
- Do not add behavioural analytics, advertising SDKs, or third-party web fonts.

Lost devices must be revoked. Users should clear offline data before transferring a device.
