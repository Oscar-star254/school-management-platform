# Teacher guide

1. Choose **Teacher** and sign in with the staff username.
2. In **Attendance**, confirm the class and date, adjust exceptions, and save.
3. In **Results**, select the allocated class and assessment, enter scores, and verify generated levels.
4. Use **Class** for competencies, values, activities, and comments if assigned as class teacher.
5. Publish assignments, materials, and class notices from their modules.
6. Check the top-bar sync state before closing the app. Offline drafts remain queued if the connection is lost.

Only enter information for assigned classes and the open term.
