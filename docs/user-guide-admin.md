# Administrator guide

Use **People** to maintain learner, guardian, and staff records. Export learner lists from the toolbar. Use **Academics** to configure terms, classes, learning areas, boundaries, allocations, report templates, and releases.

The bursar uses **Finance** for structures, invoices, payments, unmatched M-Pesa transactions, receipts, and arrears. Use **Communication** for scheduled notices and SMS delivery records.

Review **Audit log**, **Devices**, and **Backups** regularly. Revoke lost devices immediately. Branding, contacts, payment instructions, report release mode, and school identity belong in **Settings**, not source code.
