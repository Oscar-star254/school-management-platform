# Report form template

Keep one versioned template per grade band. Sections may be enabled, renamed, and ordered without changing score data. The standard order is school header, learner details, academic performance, competencies, values, co-curricular activities, attendance, comments, fees and dates, signatures, then verification.

Columns should be configured from assessment types. Do not enable class position by default. Lower-primary forms should use larger type and fewer columns; junior forms include the eight-level legend.

Before publishing a revised template:

1. Generate samples for Grades 1, 5, and 8.
2. Verify A4 portrait output and black-and-white legibility.
3. Confirm school identity, term dates, signature space, and level wording.
4. Archive the prior template version.
5. Regenerate only reports affected by the change.
